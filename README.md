# 분할매매 백테스터

종목을 입력하면 최근 10년 종가를 받아와 2모드 분할매매 전략을 백테스트하고,
다음 거래일 주문(LOC 매수 조건가·수량, 매도 목표가)을 계산합니다.

- `index.html` — 앱 본체. 단일 파일이며 별도 서버가 필요 없습니다.
- `sheets_hub.gs` — 구글시트에 붙여넣는 Apps Script. GOOGLEFINANCE로 시세를 받아 보관하고 앱에 전달합니다.

---

## 1. 구글시트 데이터 허브 만들기

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다. (이름 예: `백테스터 데이터`)
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. 기존 코드를 모두 지우고 `sheets_hub.gs` 내용을 붙여넣은 뒤 저장합니다. (Ctrl/Cmd+S)
4. 상단 함수 선택창에서 `setup` 을 고르고 **실행** 합니다.
   - 권한 요청 화면이 뜹니다. `고급` → `<프로젝트 이름>(안전하지 않음)으로 이동` → `허용`
   - 본인이 만든 스크립트이므로 정상 절차입니다.
5. 우측 상단 **배포 → 새 배포** → 톱니바퀴 → **웹 앱** 선택
   - 설명: 아무거나
   - **실행: 나**
   - **액세스 권한: 모든 사용자**
   - **배포** 를 누르고 나오는 `https://script.google.com/macros/s/..../exec` 주소를 복사해 둡니다.
6. 좌측 **트리거(시계 아이콘) → 트리거 추가**
   - 실행할 함수: `refreshWatchlist`
   - 이벤트 소스: 시간 기반 → 일 타이머 → 오전 7~8시
   - 저장

> 웹 앱 주소를 아는 사람은 이 시트에 보관된 시세를 읽을 수 있습니다. 주소는 공개하지 마세요.
> 시세 외의 개인 정보는 담기지 않습니다.

## 2. GitHub Pages에 앱 올리기

1. GitHub에서 **New repository** → 이름 예: `backtester` → **Public** → Create
   - 무료 계정은 Public 저장소만 Pages를 쓸 수 있습니다.
   - `index.html` 에는 API 키나 시트 주소가 들어 있지 않으므로 공개해도 안전합니다.
     (그 값들은 각자의 브라우저에만 저장됩니다.)
2. **Add file → Upload files** 로 `index.html` 을 올리고 **Commit changes**
3. **Settings → Pages**
   - Source: `Deploy from a branch`
   - Branch: `main` / `(root)` → **Save**
4. 1~2분 뒤 `https://<깃허브아이디>.github.io/backtester/` 로 접속됩니다.

## 3. 앱 설정 (기기마다 1회)

1. 위 주소를 엽니다.
2. **데이터 설정** 을 누르고 1단계에서 복사한 웹 앱 주소를 **구글시트 웹앱 URL** 칸에 붙여넣습니다.
3. 기본 수집 경로는 `구글시트 웹앱 먼저`, 수집 기간은 `10` 을 권장합니다.
4. 상단 입력칸에 티커를 넣고 **추가** 를 누릅니다. (`SOXL`, `AAPL`, `NASDAQ:TQQQ` 등)

## 4. 모바일 홈 화면에 추가

- **iPhone (Safari)** — 공유 버튼 → `홈 화면에 추가`
- **Android (Chrome)** — 우측 상단 ⋮ → `홈 화면에 추가` 또는 `앱 설치`

## 5. 기기 간 연동

시세 데이터는 구글시트에, 설정과 파라미터는 각 기기의 브라우저에 저장됩니다.
새 기기에서는 다음 순서로 복원합니다.

1. 데이터 설정에 웹 앱 주소를 붙여넣기
2. **시트 보관 목록 불러오기** → 시트에 있는 종목이 등록됨
3. **보유 종목 전체 갱신** → 데이터 수신

## 6. 앱 업데이트

새 `index.html` 을 같은 자리에 덮어쓰고 Commit 하면 됩니다.
반영이 늦으면 브라우저 강력 새로고침(모바일은 홈 화면 아이콘 삭제 후 재추가)을 하세요.

## 문제 해결

| 증상 | 원인과 조치 |
|---|---|
| 종목 추가 시 `구글시트: 지원하지 않음` | GOOGLEFINANCE가 해당 티커를 모릅니다. 데이터 설정에서 `NASDAQ:XXXX` 처럼 거래소를 붙여 다시 시도하세요. |
| `응답 시간 초과` | 시트가 GOOGLEFINANCE 결과를 기다리는 중입니다. 잠시 후 갱신 버튼을 다시 누르세요. |
| 웹 앱 호출이 실패 | 배포 설정의 **액세스 권한: 모든 사용자** 를 확인하세요. 코드를 고친 뒤에는 `배포 → 배포 관리 → 수정 → 버전: 새 버전` 으로 재배포해야 반영됩니다. |
| 데이터가 저장되지 않음 | 시크릿 모드이거나 저장 공간이 부족한 경우입니다. 일반 창에서 사용하세요. |
| 지수(VXN 등)가 안 받아짐 | GOOGLEFINANCE가 인덱스를 거부하면 Twelve Data 유료 플랜이 필요합니다. 대신 파라미터에서 `기준종목 실현변동성`을 대용 지표로 쓸 수 있습니다. |

## 주의

종가 기준 시뮬레이션이며 배당·분할 조정 여부는 데이터 출처를 따릅니다.
과거 성과는 미래 수익을 보장하지 않습니다. 투자 판단과 그 결과는 이용자 본인의 책임입니다.
